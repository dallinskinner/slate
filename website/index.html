A shelf, not a taskbar

A floating bottom shelf with round app icons, a launcher grid and overlapping windows. Built on KDE Plasma, styled to feel like ChromeOS.

Brave by default

Plus Files, Konsole, a PDF viewer, image viewer, video player and the Discover app store, all themed dark and lime.

Updates that just arrive

Debian security fixes, apps and Slate's own look all update through Discover. No reinstalling for new releases.

Your old MacBook, new again

Tested on the 15" Retina MacBook Pro (A1398): Broadcom Wi-Fi works out of the box, and the FaceTime camera is one click away.

Next to Windows

The installer keeps Windows and adds Slate to the boot menu, so you choose each time you start.

Light or dark, four accent colors (folders follow), and a wallpaper for every release. A quick setup greets you on first login.

Even the terminal

Type slate.

You get system info with this release's rock as the logo. slate update installs every update, and slate welcome replays the welcome.

Get Slate

Try it from a USB stick first.

  1. Build the ISO. On Debian or Ubuntu: clone the repo and run ./scripts/build-iso.sh. It makes slate-0.2-basalt-amd64.hybrid.iso (about 2.8 GB; too big for GitHub downloads for now).
  2. Write it to a USB stick (8 GB or more) with GNOME Disks, balenaEtcher or dd.
  3. Boot it. On a PC use the boot menu key (often F12); on a Mac hold Option and pick EFI Boot. Everything runs from the stick until you click Install Slate.

Already on Slate 0.1 Agate? Turn on updates once, then you're on Basalt:

curl -fsSL https://dallinskinner.github.io/slate-updates/join-updates.sh | sudo sh
